# Auto Monitor Android

Нативный Android-пульт для Auto Monitor Bot. Приложение не запускает сборщики на телефоне и не участвует в горячем пути обнаружения объявлений. Оно подключается к защищенному Dashboard на ноутбуке и поэтому не замедляет мониторинг.

## Возможности

- запуск, остановка и LIVE-режим мониторинга;
- ручное сканирование;
- полный редактор фильтров и географии;
- управление источниками;
- объявления, логи, план поиска и настройки;
- сохранение адреса сервера и сессии входа;
- диагностика соединения, повторное подключение и безопасное открытие внешних ссылок;
- поддержка локальной сети, Tailscale и HTTPS-адреса.

## Подключение

Готовый APK использует приватное имя ноутбука в Tailscale и автоматически пробует домашний адрес как резервный. Адрес можно изменить кнопкой с шестеренкой. Порт `3001` не публикуется в обычный интернет.

Однократная настройка удаленного доступа на ноутбуке:

```powershell
pnpm remote:setup
```

На Android нужно установить Tailscale и войти в тот же аккаунт, что и на ноутбуке. После этого приложение работает через Wi-Fi и мобильный интернет из любой точки. Tailscale на Windows работает в unattended-режиме, поэтому приватная сеть поднимается до входа пользователя в профиль.

Приложение не содержит логин, пароль, Telegram-токен или внутренний API-токен. Авторизация выполняется существующей страницей Dashboard, а защищенная cookie хранится в приватном хранилище Android WebView.

## Сборка

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

Скрипт хранит JDK, Android SDK, Gradle cache и ключ подписи только в `D:\auto-monitor-bot\.runtime\android*`. Готовый APK копируется в корень проекта под именем `Auto-Monitor-Bot-Android.apk`.
