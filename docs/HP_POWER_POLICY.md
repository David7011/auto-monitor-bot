## Управление

Из корня проекта:

```powershell
.\amb.cmd power:check
.\amb.cmd power:configure
.\amb.cmd local:status
```

`power:check` только читает активную схему. Ненулевой таймер, недоступность
настроек или смена схемы в процессе проверки дают exit 1. `local:status`
в активной monitoring-сессии включает эту проверку и также возвращает ошибку.
Это проверка при вызове команды, не отдельная служба непрерывного контроля.

`power:configure` сохраняет значения в `.runtime/power-policy/before-*.json`,
изменяет только три таймера активной схемы для AC/DC, применяет схему и
повторно читает результат. При ошибке применения пытается вернуть исходные
значения. Другие схемы не переписываются; после ручной смены схемы следует
проверить питание снова.

Исходный снимок этого исправления:
`.runtime/power-policy/before-20260908-205511-813.json`.
Для точечного отката использовать `scheme`, `settings[].Guid`, `ACSeconds`,
`DCSeconds` из снимка с `powercfg /setacvalueindex` и `/setdcvalueindex`,
группа Sleep `238c9fa8-0aad-41ed-83f4-97be242c8f20`. Затем применить эту схему
через `/setactive`, только если она по-прежнему нужна пользователю.
Откат вернёт автоматический сон и вновь сделает `power:check` красным.

- Рестарт проекта, сон, перезагрузка и отключение питания для теста не выполнялись.

Настройки запрещают переход по этим автоматическим таймерам. Они не отменяют
ручной сон/выключение, действия других программ через системный API,
критический разряд, тепловую защиту или перезапуск Windows.
