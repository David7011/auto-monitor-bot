Статус: **код и локальные проверки готовы; НЕ выпущено**. По указанию пользователя общий выпуск откладывается до завершения третьего этапа. Работающий release не пересобирался и не перезапускался. LIVE-проверка эффекта остаётся обязательной после общего выпуска.

## Изменение

Раньше recovery сравнивал ожидаемое время запуска со временем завершения сканирования. При допуске 9 секунд обычный своевременный скан длительностью 11–30 секунд открывал ложное OFFLINE_WINDOW.

Теперь collector передаёт фактический `startedAt`, уже зафиксированный перед сбором. `OlxOutageSchedule` требует этот факт; детектор больше не принимает общее `now`, которое можно было случайно подменить временем завершения. При отсутствующем/невалидном start evidence окно не выдумывается. Время завершения по-прежнему используется для существующих расчётов lookback и записи результата.

Изменены три production-файла: `collector-run.ts`, `source-search-plan.ts`, `olx-outage-detection.ts`. Схема БД, cadence, допуск, origin concurrency, существующие recovery windows и настройки питания не менялись. Исправление относится к позднему старту scheduled run; отдельный детектор сна внутри уже начатого скана этим небольшим patch не добавляется.
