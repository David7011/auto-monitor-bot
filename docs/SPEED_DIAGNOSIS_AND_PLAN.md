# Диагностика скорости OLX + план апгрейда (данные, не догадки)

Дата: 2026-07-17. Жалоба: раньше OLX ловился за 5–10 мин, сейчас стабильно 20–30 мин.

## Что показали замеры по рабочей БД и живой ленте

**Пайплайн здоров и быстр — регрессии в НАШЕМ коде нет:**
- Мониторинг RUNNING, OLX ACTIVE, healthScore 100.
- Realtime крутится ровно по расписанию: 1265 успешных прогонов за 90 мин, интервал p50 = 3.997 c (настроено 4 c).
- **0 инцидентов защиты (429/CAPTCHA) за 3 часа**, пауз нет. Капча НЕ виновата.
- Объявления ловятся именно realtime-контуром (29 из 37 за 6ч), а не медленным backfill.

**Задержка — на стороне OLX (модерация/индексация), не у нас:**
- OLX за 6ч: 37 объявлений, задержка `created_time → обнаружение` **p50 = 26 мин, p90 = 99 мин, минимум = 11.7 мин**.
- **Ни одно OLX-объявление не поймано быстрее 11.7 мин.** Это твёрдый «пол»: объявления просто не появляются в поисковом API OLX (`sort_by=created_at:desc`) раньше ~12 минут после своего `created_time`.
- Живой зонд ленты подтвердил: самое свежее объявление в ленте прямо сейчас ~12 мин по `created_time`. Свежее — только «поднятые» (bump) старые объявления (fresh `last_refresh`, старый `created`), это не новые.

**Доказательство, что дело в площадке, а не в пайплайне:**
- **Cars.ua: объявление поймано за 6 секунд** (0.1 мин). Не-OLX площадки индексируют почти мгновенно.
- **AUTO.RIA: 0 объявлений** — источник включён, ключ настроен, но **ни один фильтр его не targeting** (оба боевых фильтра: `["OLX","RST","CARS_UA","AUTOMOTO"]`). Официальный быстрый API простаивает.

**Вывод.** «20–30 мин на OLX» — это задержка модерации самого OLX (в UA она заметно выросла за 2025–2026). Опросом ленты её пробить нельзя: пока OLX не пропустил объявление в поиск, его нет НИ в одном эндпоинте (API/мобайл/HTML — один и тот же индекс). «Раньше было 5–10 мин» — OLX ужесточил модерацию и/или раньше была другая конфигурация; наш код с тех пор только здоровее (4 c вместо 5 c, адаптивная пагинация, нулевые блоки).

Реальная скорость берётся не выжиманием OLX, а **диверсификацией на быстрые площадки** и **действием за секунды**.

## План апгрейда (по убыванию влияния на реальную скорость)

### Tier 1 — Быстрые площадки (собственно «находить быстрее») ⭐

- **1A. Активировать AUTO.RIA.** Добавить `AUTO_RIA` в боевые фильтры. Это выделенная
  автоплощадка с официальным API (ключ уже есть), быстрым и точным (`addDate`, часто
  телефон). Сейчас он мёртв — ни один фильтр его не выбирает. Большинство машин
  дублируются на OLX и AUTO.RIA; на AUTO.RIA та же машина всплывает на минуты раньше.
  Квота free-tier (30/час) ограничивает опрос до ~6 мин, но если AUTO.RIA индексирует
  за ~2 мин, итоговая задержка ~3–8 мин — в 3–4 раза лучше OLX. Самый большой доступный рычаг.
- **1B. Поднять роль Cars.ua.** Уже доказал 6 секунд. Включён, работает — усилить охват.
- **1C. Кросс-источниковый дедуп.** Смотреть OLX + AUTO.RIA + Cars.ua на одну машину,
  слать на той площадке, что всплыла первой, и не дублировать в Telegram. Dedup-guard
  уже есть по `canonicalUrl`/`externalId`; расширить на кросс-источник по
  VIN/номеру/телефону/(марка+модель+год+цена)-фингерпринту. Файл: `modules/duplicate-guard.ts`.

### Tier 2 — Выигрывать гонку, которую нельзя выиграть опросом: действовать за секунды ⭐

Если «пол» OLX ~12 мин общий для всех (и для перекупов тоже), выигрывает тот, кто
**первым позвонит**. Сейчас в сообщении одна кнопка «Открыть».

- **2A. Телефон продавца + кнопка «Позвонить» (`tel:`)** в первом сообщении (см.
  [[COMPETITIVE_EDGE_PLAN]] A1). Звонок в один тап за 2 секунды вместо 20–30 секунд ручного пути.
- **2B. Решение в первом сообщении** — цена, вердикт «ниже/выше рынка», год/пробег/город,
  red-flag — сразу, а не в фоновом обновлении.
- **2C. Громкий алерт на «горячие»** (ниже рынка) — бросать всё и звонить.

### Tier 3 — Выжать сам OLX (маргинально, но сделать)

- **3A. Опциональный детект «поднятых».** В агрессивном режиме считать кандидатом
  свежеподнятое объявление (`last_refresh` недавний, даже если `created` старый) —
  ловит перевыставления перекупов и снижения цены. По умолчанию выкл (спам), вкл на охоту.
- **3B. Ноль добавленной задержки** — inline-отправка в Telegram уже мгновенная; следить,
  чтобы очередь не копилась (сейчас чисто).
- **3C. НЕ давить интервал OLX ниже 4 c.** Суб-4с не пробьёт 12-минутный пол, только
  поднимет риск капчи (сейчас 0 инцидентов). Силы — в Tier 1, не сюда.

### Tier 4 — Надёжность и наглядность

- **4A. 24/7 без сна ноутбука** (см. [[COMPETITIVE_EDGE_PLAN]] E1) — ночные объявления.
- **4B. Задержка по источникам на дашборде** — показывать p50 `публикация→обнаружение`
  на источник, чтобы видеть, что OLX медленный, а AUTO.RIA/Cars.ua быстрые, и доверять
  быстрым полосам. Метрика уже считается в диагностике — вывести в UI.
- **4C. Держать капчу на нуле** — анти-блок работает (0 инцидентов), не ломать.

## Порядок внедрения

1. **1A** — добавить AUTO_RIA в фильтры (5 минут, измерит себя сам). Проверить задержку через сутки.
2. **2A + 2B + 2C** — телефон + «Позвонить» + решение/приоритет в первом сообщении.
3. **1B + 1C** — усилить Cars.ua + кросс-дедуп.
4. **4A + 4B** — 24/7 + задержка по источникам на дашборде.
5. **3A** — режим «поднятых» для охоты.

## Честный итог

OLX = ~12–26 мин из-за модерации OLX, не из-за нас, и опросом это не лечится. Быстрее
перекупов вы станете за счёт: **(1) быстрых площадок (AUTO.RIA/Cars.ua ловят за
секунды-минуты), (2) звонка за 2 секунды после находки, (3) эфира 24/7.** Именно это и строим.
