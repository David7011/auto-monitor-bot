# План: обгонять перекупов — быстрее находить и первым связываться

Дата: 2026-07-17. Продолжение [[OLX_UPGRADE_PLAN]]. Всё бесплатно, только диск D.

## Честная физика (чтобы план был про реальные рычаги, а не про магию)

Когда продавец публикует объявление, есть **общий для всех потолок** — задержка
индексации самого OLX (секунды–минута), пока карточка появится в API/выдаче.
Ни вы, ни перекуп не пробиваете этот потолок опросом ленты. Поэтому «увидеть на
секунду раньше» — не то поле, где выигрывается война.

Война выигрывается на трёх фронтах, и на всех трёх вы сейчас можете вырваться вперёд:

1. **Никогда не пропускать.** Перекупы теряют объявления на всплесках и в простои. Вы — нет.
2. **Связаться за секунды.** Увидеть И позвонить продавцу раньше конкурента. Сейчас недостроено — здесь самый большой выигрыш.
3. **Быть в эфире 24/7.** Перекупы крутят ботов круглосуточно. Ноутбук, который спит, проигрывает.

Ранжирование по реальному влиянию: **Раздел 1 > Раздел 2 > Раздел 5 > Раздел 3 > Раздел 4 > Раздел 6.**

## Раздел 1. Мгновенный отклик = контакт за секунды ⭐ ГЛАВНОЕ

Сейчас первое сообщение содержит только кнопку «Открыть объявление». Чтобы
позвонить, надо: открыть OLX → нажать «показать телефон» → дождаться → набрать.
Это 15–30 секунд, за которые перекуп уже звонит. Здесь и проигрывается гонка.

- **A1. Извлекать телефон продавца в первое сообщение + кнопка «Позвонить» (`tel:`).**
  OLX отдаёт номер отдельным запросом по id объявления (эндпоинт вида
  `/api/v1/offers/{id}/limited-phones/` — точный путь уточнить в DevTools, может
  требовать токен сессии/капчу). Телефон кладём в сообщение и в кнопку `tel:` —
  звонок в один тап за 2 секунды. Это **самая весомая правка** во всём плане.
  Файлы: `collectors/olx.ts` (дозапрос телефона), `modules/telegram-service.ts`
  (`listingButton` → добавить `tel:` и «Написать»). Осторожно: телефон дёргать
  только для **совпавших** объявлений (не для всех подряд), чтобы не ловить блок.

- **A2. Кнопка «Написать продавцу» с готовым текстом.** Deep-link в OLX-чат или
  копируемый шаблон первого сообщения («Здравствуйте, авто актуально? Готов
  подъехать сегодня»). Убирает время на набор.

- **A3. Решение в первом сообщении, а не в фоновом обновлении.** Дешёвые сигналы
  (цена, вердикт «ниже/выше рынка», год, пробег, город, red-flag по ключевым
  словам) поднять в ПЕРВОЕ сообщение. Сейчас вердикт рынка приходит фоном позже —
  пользователь должен решать «звонить ли» мгновенно, а не через 5 секунд.

- **A4. Приоритет «горячих» сделок.** Объявления ниже рынка — отдельным громким
  алертом (другой эмодзи/звук/пометка «🔥 НИЖЕ РЫНКА»), чтобы бросать всё и звонить.
  Обычные — тихо. Экономит внимание на том, что реально важно.

## Раздел 2. Никогда не пропускать (перекупы теряют — вы нет)

- **B1. Адаптивный интервал по нагрузке.** Мы уже добавили «сентинел переполнения»
  (`OLX realtime window overflow`). Завязать на него автоскорость: при всплеске
  публикаций интервал сам сжимается (4с → 2с), в тишину — расслабляется. Так пик
  трафика не переполняет окно. Файлы: `orchestrator.ts` (динамический
  `nextCheckAt`), сигнал из `collector-run`.

- **B2. Целевые фиды под каждый активный фильтр.** Помимо широкой ленты newest —
  отдельный query-фид на конкретные марки/модели пользователя. Тогда «его» машины
  ловятся даже когда широкое окно на 250 позиций переполнено. Файл: `olx.ts`
  (`buildSourceSearchPlan` для OLX уже умеет brand/models — расширить).

- **B3. Сильнее опираться на официальный AUTO.RIA API.** Он быстрый, точный, даёт
  `publishedAt` и часто телефон — вторая быстрая полоса без риска блокировки.
  Поднять его частоту в рамках квоты (сейчас 20 запросов/час — проверить, можно ли
  выше по вашему тарифу).

- **B4. Соседние категории OLX.** Если ваши авто выходят за категорию 108
  (кроссоверы/микроавтобусы/мото) — добавить их в охват.

## Раздел 3. Скорость обнаружения (срезаем управляемую задержку)

- **C1. Интервал OLX 4с → 2–3с** — вместе с уже сделанным анти-блоком (реальный UA,
  джиттер). Сначала неделю померить частоту 429/CAPTCHA; если чисто — снижать.
- **C2. Инлайнить realtime-скан OLX** мимо очереди BullMQ (сейчас планировщик →
  Redis → воркер добавляет десятки мс). Имеет смысл только при уходе в суб-секунду.
- **C3. Больше соединений на origin** (`SOURCE_HTTP_CONNECTIONS_PER_ORIGIN` 4 → 6–8)
  при нескольких гео-фидах.
- Честно: ниже ~2–3с доминирует индексация OLX; дальнейшее сжатие даёт мало, а риск
  блока (= тёмные окна = пропуски) растёт. Это уже проигрышный размен.

## Раздел 4. Правильные объявления, не только быстрые

- **D1. Предпрогрев оценки рынка** на каждый активный фильтр, чтобы вердикт
  «ниже/выше рынка» был готов уже в момент обнаружения (см. A3), а не считался после.
- **D2. Детект перевыставленных.** Перекупы переставляют объявления. Ловить один и
  тот же авто по VIN/фото/телефону и помечать «переставлено» vs реально новое —
  чтобы не звонить второй раз и видеть «висяки».
- **D3. Тип продавца: частник vs перекуп/салон.** Мы уже добавили опциональный
  приватный фид (`OLX_PRIVATE_FEED_ENABLED`, `owner_type=private`). Включить и
  помечать частников — свежие сделки обычно у них, а перекупов можно фильтровать.
- **D4. Скоринг рисков/скама.** Слишком дёшево + сток-фото + рисковые слова → метка
  «проверь внимательно», чтобы не тратить звонок на развод.

## Раздел 5. Всегда в эфире 24/7 ⭐ (скучный, но решающий рычаг)

README прямо говорит: автозапуск работает, только пока ноутбук включён. Перекупы
крутят ботов круглосуточно — спящий ноутбук проигрывает объявления, опубликованные
ночью/днём, когда вас нет.

- **E1. Постоянно включённое устройство.** Реалистично-бесплатно: выключить сон на
  ноутбуке (питание «высокая производительность», не гасить при закрытии крышки), или
  перенести проект на запасной мини-ПК / всегда-включённую машину. Truly-free 24/7
  облако под этот стек (Postgres+Redis+worker) не тянет — честно.
- **E2. Харденинг watchdog** (уже есть): само-восстановление после блока, алерт в
  Telegram когда упал сам бот, а не источник.

## Раздел 6. Обратная связь: измерять, что реально впереди

- **F1. Метрика «время до контакта».** publication → detection → telegram → (вы
  позвонили). Сейчас меряется до Telegram; добавить исход.
- **F2. Частота блокировок по интервалу** — чтобы безопасно давить газ (C1).
- **F3. «Поймано backfill, а не realtime»** — если стабильно > 0, окно мелкое,
  усиливать B1/B2.

## Порядок внедрения (по убыванию отдачи)

1. **A1 + A3 + A4** — телефон + кнопка «Позвонить» + решение и «горячие» в первом
   сообщении. Это превращает «увидел» в «позвонил за 2 секунды». Самый большой скачок.
2. **E1** — вывести бота в режим 24/7 (настройки питания или отдельное устройство).
3. **B1 + B3** — адаптивная скорость + вторая полоса AUTO.RIA.
4. **A2 + D3 + D1** — шаблон письма, приоритет частников, готовый вердикт рынка.
5. **C1** — интервал 3с после недели чистой статистики по блокам.
6. **D2 + D4 + F**\* — перевыставленные, скам-скоринг, метрики.

Проверки после каждого шага: `pnpm typecheck && pnpm lint && pnpm test`, затем
`/observations/summary` и метрики задержек.

## Замечание про ожидания

«1000% вперёд всегда» — недостижимо физически: общий потолок индексации OLX один для
всех. Но связка «никогда не пропускаю + звоню за 2 секунды + в эфире 24/7» реально
ставит вас впереди большинства перекупов на массовых площадках. Именно её и строим.
